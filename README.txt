ASİSTANIM v0.3 — iPhone PWA kaynak paketi\n\nÇalışan: yerel parçalı mikrofon kaydı, kesinti sonrası kayıt kurtarma denemesi, önemli an işaretleme, görevler (üç görünüm, öncelik, proje), yönetici özeti, toplantıya transkript TXT/yapıştırma, kural tabanlı karar/görev/risk adayları, arşiv araması, JSON ses dahil yedek/geri yükleme.\n\nÇalışmayan/entegrasyon bekleyen: otomatik Türkçe konuşma tanıma, yapay zekâ modeliyle analiz, arka plan/kilit ekranında güvenilir kayıt, sunucu yedeklemesi, cihazlar arası eşitleme, push bildirim.\n\nBu prototip gizli kurumsal kayıtlar için onaylanmış güvenli altyapı değildir. HTTPS üzerinde yayınlanması ve gerçek iPhone testleri gerekir.\n
